Esercizio


Consideriamo la funzione \[ f(x) = \sqrt{2x^2 -7x + 5} \] Individuare il dominio della funzione \(f\)
(ovvero individuare tutti i valori della \(x\) per i quali la funzione è definita)

Soluzione:
La funzione è definita per
\(x \leq 1\,\,\,\)
oppure
\(\,\,\,x \geq \dfrac{5}{2}\)
ovvero il suo dominio è l'insieme \[ D = \Big(-\infty\,,\,\,1\Big] \cup \Big[\dfrac{5}{2}\,,\,\,+\infty\Big) \]




Esercizio


Consideriamo la funzione \[ f(x) = \sqrt{\dfrac{-7x + 9}{2x + 3}} \] Individuare il dominio della funzione \(f\)
(ovvero individuare tutti i valori della \(x\) per i quali la funzione è definita)

Soluzione:
La funzione è definita per \[ -\dfrac{3}{2} \lt x \leq \dfrac{9}{7} \] quindi il suo dominio è l'insieme \[ D = \Big(-\dfrac{3}{2}\,,\,\,\dfrac{9}{7}\Big] \]

Esercizio


Consideriamo la funzione \(f\) contenente un parametro \(a \in \mathbb{R}\) \[ y = \dfrac{\sqrt{4x - a}}{x^2} \]
  1. Stabilire il dominio di \(f\).

    Osservazione:
    Gli estremi del dominio dipenderanno dal valore del parametro \(a\).


    Soluzione
    Il dominio della funzione è \[ D = \begin{cases} \Big[\dfrac{a}{4}\,;\,\,0 \Big) \cup \left(0\,;\,\,+\infty\right) \,\,\,&\text{se}\,\,\, a \lt 0 \\\\ \left(0\,;\,\,+\infty\right) \,\,\,&\text{se}\,\,\, a = 0 \\\\ \Big[\dfrac{a}{4}\,;\,\,+\infty\Big) \,\,\,&\text{se}\,\,\, a \geq 0 \end{cases} \]

  2. Stabilire per quali valori di \(a\) la funzione è tale che \(f(1) = 2\)

    Soluzione: \(\,\,\, a = 0\)

  3. Stabilire per quali valori di \(a\) il dominio della funzione è \[ [\sqrt{2};\,\,+\infty) \]
    Soluzione \(\,\,\, a = 4\,\sqrt{2}\)

  4. Scegliamo \(1\) come valore del parametro \(a\). Di conseguenza la funzione \(f\) è \[ y = \dfrac{\sqrt{4x - 1}}{x^2} \] Determiare per quali valori della \(x\) si ha \(f(x) \lt 0\).
