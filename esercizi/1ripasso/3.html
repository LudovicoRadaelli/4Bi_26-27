Esercizio


Consideriamo la funzione \[ f(x) = \dfrac{\sqrt{x^2 + 4x + 9}}{4x - 3} \] Individuare il dominio della funzione \(f\).

Soluzione:
La funzione è definita per \[ x \neq \dfrac{3}{4} \] quindi il suo dominio è l'insieme \[ D = \left(-\infty\,,\,\,\dfrac{3}{4}\right) \cup \left(\dfrac{3}{4}\,,\,\,+\infty\right) \]




Esercizio


Studiare il dominio della funzione \[ f(x) = \dfrac{\sqrt{4x + a}}{x - 1} \] al variare del valore del parametro \(a\).

Soluzione
  • se \(\,\,a \lt -4\,\,\) allora \[ D = \Big[-\dfrac{a}{4}\,,\,\,+\infty\Big) \]

  • se \(\,\,a \gt -4\,\,\) allora \[ D = \Big[-\dfrac{a}{4}\,,\,\,1\Big) \cup (1\,,\,\,+\infty) \]

  • se \(\,\,a = -4\,\,\) allora \[ D = (1\,,\,\,+\infty) \]
